Selamat datang di repositori portofolio web saya! Repositori ini berisi kode sumber (*source code*) untuk website portofolio pribadi saya sebagai **Web Developer** dan siswa **PPLG** (Pengembangan Perangkat Lunak dan GIM) di SMK Negeri 3 Metro.

---

## 📌 Tentang Portofolio

Website ini dibuat untuk menampilkan:
- 👤 **Profil & Bio Ringkas**: Latar belakang, pendidikan, dan minat.
- 🛠️ **Tech Stack & Keahlian**: Bahasa pemrograman dan framework yang dikuasai (HTML, CSS, JS, PHP, Laravel, Git/GitHub, MySQL).
- 🎮 **Hobi & Personalitas**: Aktivitas seperti catur (Chess.com ELO 1000), penikmat MotoGP, dan eksplorasi game.
- 📱 **Kontak & Social Media**: Link langsung ke Instagram, Facebook, TikTok, dan GitHub.

---

## 🛠️ Teknologi yang Digunakan

* **Frontend**: HTML5, CSS3, JavaScript (ES6+), Bootstrap 5.3, Bootstrap Icons
* **Backend & Tools**: PHP, Laravel, Git & GitHub
* **Typography**: Google Fonts (*Plus Jakarta Sans*)
